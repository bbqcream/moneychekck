# 페이플랜

앞으로 들어올 월급과 지원금을 바탕으로 돈 계획을 적고, 각 항목을 처리한 뒤 남는 돈을 확인하는 앱입니다.

## 실행

Node.js 22.13 이상과 pnpm 11이 필요합니다.

~~~sh
pnpm install
pnpm dev
~~~

[로컬 앱](http://localhost:3000)에서 **새 시나리오**를 만들거나 **예시로 시작**을 선택하세요. 입금을 추가하고, 입금 아래에 지출·저축·투자·상환·송금 항목을 작성할 수 있습니다. 시나리오 하나를 비교 화면의 양쪽에 선택하면 확실한 돈만 넣었을 때와 전체 입금을 넣었을 때를 비교할 수 있습니다.

## 구현 계획

1. 계산 엔진에서 금액을 원 단위 정수로 변환하고, 입금과 항목을 순서대로 처리해 잔액 범위를 계산합니다. AGENTS.md의 96만원 예제로 각 단계의 잔액을 검증합니다.
2. 시나리오 목록과 편집 타임라인을 만들고, 입력과 수정 내용을 Zustand를 통해 브라우저 저장소에 저장합니다.
3. 근무수당 계산기와 시나리오 비교를 연결하고, 아이폰 메모 복사용 평문과 전체 JSON 백업을 제공합니다.
4. 타입 검사와 린트, 테스트를 통과한 정적 빌드를 Vercel에서 배포할 수 있게 준비합니다.

## 계산과 저장

- 잔액은 좋은 경우에서 나쁜 경우 순으로 표시합니다. 나쁜 경우 잔액이 음수이면 **모자람**을 표시합니다.
- 반복 항목은 하루 또는 한 달 금액에 입력한 일수나 개월 수를 곱해, 지정한 입금 아래에서 한 번에 계산합니다.
- 근무수당 계산기는 한국 공휴일과 주말을 제외합니다. 포함된 공휴일 데이터는 2018~2027년이며, 다른 연도를 선택하면 근무일수를 확인하라는 안내를 표시합니다.
- 세금은 기본적으로 적용하지 않습니다. 세금 옵션을 켜면 시나리오의 각 입금액에 적용하고 세액의 원 미만은 버립니다.
- 데이터는 현재 브라우저의 localStorage에 저장합니다. 목록의 **전체 JSON 내보내기**로 백업 파일을 저장할 수 있습니다.

## 검증과 배포

~~~sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
~~~

pnpm build는 out/에 정적 파일을 생성합니다. Vercel에서 Next.js 프로젝트로 연결하고 pnpm build로 빌드합니다. 목록, 편집, 비교 화면은 URL 해시를 사용해, 앱을 한 번 열면 브라우저 안에서 화면을 이동하고 계산할 수 있습니다.
